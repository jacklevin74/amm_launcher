# AMM Initialization Guide

Complete guide to initializing the XNT/USDC Bonding Curve AMM on a local Solana validator.

## Prerequisites

- Solana CLI installed (`solana --version`)
- Anchor CLI installed (`anchor --version`)
- Node.js 18+ (`node --version`)
- Rust/Cargo installed (`rustc --version`)

## Quick Start (Recommended)

The fastest way to get everything running:

```bash
# 1. Configure Solana CLI for localhost
solana config set --url http://localhost:8899 --keypair ~/.config/solana/id.json

# 2. Start validator with funds minted directly to your wallet
pkill -9 solana-test-validator 2>/dev/null
rm -rf test-ledger
solana-test-validator --reset --mint $(solana address) &

# 3. Wait for validator and deploy
sleep 5
anchor build
anchor deploy --provider.cluster http://localhost:8899

# 4. Initialize pool
ANCHOR_PROVIDER_URL=http://localhost:8899 ANCHOR_WALLET=~/.config/solana/id.json npx ts-node scripts/init-pool-native-mint.ts

# 5. Start web server
cd web && node server.js &
```

Visit: http://localhost:3030/trading

## Step-by-Step Manual Process

### Step 1: Configure Solana CLI

**IMPORTANT**: The Solana CLI must be configured to use localhost, not a remote network.

```bash
# Check current config
solana config get

# Set to localhost with your keypair
solana config set --url http://localhost:8899 --keypair ~/.config/solana/id.json

# Verify
solana config get
# Should show:
# RPC URL: http://localhost:8899
# Keypair Path: /Users/<you>/.config/solana/id.json
```

### Step 2: Start Test Validator

**Option A: With --mint flag (Recommended)**
```bash
# Stop any existing validator
pkill -9 solana-test-validator

# Clean up old ledger
rm -rf test-ledger

# Start with 500M SOL minted to your wallet
WALLET_ADDRESS=$(solana address)
solana-test-validator --reset --mint $WALLET_ADDRESS > /tmp/validator.log 2>&1 &

# Wait for startup
sleep 5

# Verify
solana cluster-version
solana balance  # Should show 500000000 SOL
```

**Option B: Transfer from faucet**
```bash
# Start validator without --mint
solana-test-validator --reset > /tmp/validator.log 2>&1 &
sleep 5

# Transfer from faucet (has 1M SOL by default)
WALLET_ADDRESS=$(solana address)
solana transfer $WALLET_ADDRESS 500000 \
  --from test-ledger/faucet-keypair.json \
  --allow-unfunded-recipient \
  --fee-payer test-ledger/faucet-keypair.json
```

### Step 3: Build and Deploy Program

```bash
# Build the Anchor program
anchor build

# Deploy to local validator
anchor deploy --provider.cluster http://localhost:8899

# Verify deployment
solana program show 2zKpM4k4kp7qRNvBVzkEAAt8DU8t1vpAfzsRagha4NNF
```

### Step 4: Initialize Pool

```bash
# Run the initialization script
ANCHOR_PROVIDER_URL=http://localhost:8899 \
ANCHOR_WALLET=~/.config/solana/id.json \
npx ts-node scripts/init-pool-native-mint.ts
```

This script:
- Creates USDC mint (6 decimals)
- Uses native wSOL as XNT (9 decimals)
- Initializes pool with 10M wSOL and 10M virtual USDC
- Creates trader wallet at `/tmp/trader-wallet.json`
- Funds trader with 10M SOL and 10M USDC
- Funds ceiling reserve with 10M wSOL
- Updates `web/pool-config.json` with new addresses

### Step 5: Start Web Server

```bash
cd web
node server.js > /tmp/server.log 2>&1 &

# Or run in foreground to see logs
node server.js
```

Web interface available at:
- http://localhost:3030/trading - Main trading interface
- http://localhost:3030/tron - Tron aesthetic version
- http://localhost:3030/admin - Admin panel

## Using the Automated Script

There's a convenience script that does most of this:

```bash
./scripts/start-validator-and-init.sh
```

**Note**: This script assumes the faucet has enough SOL. If you need more than 50M SOL, use the manual process with `--mint` flag instead.

## Key Scripts Reference

| Script | Purpose |
|--------|---------|
| `scripts/init-pool-native-mint.ts` | Full pool initialization with wSOL |
| `scripts/init-pool-simple.ts` | Simpler pool init (alternative) |
| `scripts/check-pool.ts` | Check pool state |
| `scripts/check-pool-balances.ts` | Check pool token balances |
| `scripts/check-trader-balance.ts` | Check trader wallet balances |
| `scripts/demo-trade.ts` | Execute demo trades |
| `scripts/add-virtual-usdc.ts` | Add virtual USDC (raise price) |
| `scripts/deposit-usdc.ts` | Deposit real USDC to pool |

## Troubleshooting

### "No default signer found"
```bash
# Solana CLI not configured properly
solana config set --keypair ~/.config/solana/id.json
```

### "Account has insufficient funds"
```bash
# Need more SOL - restart validator with --mint
pkill -9 solana-test-validator
rm -rf test-ledger
solana-test-validator --reset --mint $(solana address) &
```

### "fetch failed" from API
```bash
# Pool doesn't exist on current validator - reinitialize
ANCHOR_PROVIDER_URL=http://localhost:8899 \
ANCHOR_WALLET=~/.config/solana/id.json \
npx ts-node scripts/init-pool-native-mint.ts
```

### "Account does not exist"
```bash
# Pool config has old address - restart web server after init
pkill -f "node server.js"
cd web && node server.js &
```

### Validator not responding
```bash
# Check if running
lsof -ti:8899

# Check logs
tail -f /tmp/validator.log

# Restart
pkill -9 solana-test-validator
solana-test-validator --reset --mint $(solana address) &
```

## Stopping Services

```bash
# Stop validator
pkill solana-test-validator

# Stop web server
pkill -f "node server.js"

# Or kill by port
lsof -ti:8899 | xargs kill -9  # validator
lsof -ti:3030 | xargs kill -9  # web server
```

## Pool Parameters

Default initialization values:
- **XNT (wSOL) Reserve**: 10,000,000 (10M)
- **Virtual USDC Reserve**: 10,000,000 (10M)
- **Initial Price**: $1.00
- **Price Floor**: $1.00
- **Price Ceiling**: $2.00
- **Ceiling Reserve**: 10,000,000 wSOL

## Environment Variables

| Variable | Default | Description |
|----------|---------|-------------|
| `ANCHOR_PROVIDER_URL` | http://localhost:8899 | Solana RPC endpoint |
| `ANCHOR_WALLET` | ~/.config/solana/id.json | Wallet keypair path |
